# سورس و محتوای نسخهٔ وردپرس باراد

نسخهٔ ثبت‌شده در ۹ اکتبر ۲۰۲۶: افزونهٔ اختصاصی باراد، چهار فایل سفارشی قالب فرزند، دادهٔ بومی المنتور و ووکامرس و رسانه‌های مورد استفاده. سایت فارسی ۱۴۱ کالای منتشرشده، چهار دستهٔ اصلی و ۱۳ برگه (شامل پیش‌فاکتور) دارد. ۱۴۱ ترجمهٔ کالا و ۱۲ برگهٔ انگلیسی پیش‌نویس‌اند.

## اجزای بسته

- `wp-content/plugins/barad-site`: منطق سایت، جست‌وجو، استعلام، فرم‌ها، قیمت‌گذاری گروهی، اتصال سئو و زبان، CSS و JavaScript اختصاصی.
- `wp-content/themes/woodmart-child`: چهار فایل سفارشی اجرا؛ قالب والد و فونت‌های تجاری در بسته نیستند.
- `content/site.json`: فقط صفحات، کالاها، دسته‌ها، رسانه‌ها و تنظیمات عمومیِ مجاز. حساب‌ها، رمزها، سفارش‌ها، درخواست‌های مشتریان، توکن‌ها و کلیدهای سرویس صادر نشده‌اند.
- `media`: رسانه‌های اصلی با هش SHA-256؛ فایل‌های مشتق را وردپرس هنگام ورود دوباره می‌سازد.
- `docs`: شرح ورود کالاها، سئوی محلی، زبان‌ها و استفاده از کاتالوگ.

## اجرای وردپرس

۱. یک وردپرس تازه روی هاست PHP و MySQL/MariaDB نصب و حساب مدیر را از نصب عادی ایجاد کنید. نسخهٔ محلی با PHP 8.3، WordPress 7.1، WooCommerce 10.9.4، Elementor 4.3.3 و WoodMart 8.6.4 آزموده شده است.
۲. وودمارت، ووکامرس و المنتور را از منابع مجاز خودتان نصب کنید. Elementor Pro، Yoast SEO، Yoast Local و WPML افزونه‌های جداگانه‌اند؛ بسته‌ها و لایسنس‌های فروشنده در این مخزن قرار نمی‌گیرند. در صورت نیاز به همان ساختار، نسخهٔ سالم و سازگار این افزونه‌ها را تهیه و نصب کنید.
۳. فایل‌های سفارشی را در `wp-content` کپی و قالب فرزند و افزونهٔ Barad Site را فعال کنید. افزونهٔ باراد هنگام اجرا به WooCommerce وابسته است.
۴. پس از پشتیبان‌گیری، فقط روی نصب تازه اجرا کنید:

```sh
php tools/import-site.php --wp=/absolute/path/to/wordpress --dry-run
php tools/import-site.php --wp=/absolute/path/to/wordpress --apply
```

ابزار مسیر فایل‌ها و هش رسانه‌ها را کنترل و شناسهٔ رسانه، برگه، کالا و دسته را نگاشت می‌کند. این ابزار برای به‌روزرسانی فروشگاه فعال یا ادغام با موجودی قبلی نوشته نشده است. اجرای کامل ابزار مهاجرت روی هاست تازه هنوز آزموده نشده؛ پیش از استفادهٔ عملی، مهاجرت را در محیط آزمایشی بررسی کنید. نسخهٔ فعلی سایت محلی و داده‌های خروجی بررسی شده‌اند.

۵. لینک‌های تصاویر کوچک و srcset داخل HTML قدیمی را پس از ورود با بازتولید CSS و رسانه‌های المنتور/وردپرس بازبینی کنید. اطلاعات تماس، قالب، خانهٔ ثابت، قیمت‌گذاری و گالری‌ها را روی دامنهٔ مقصد کنترل کنید. همهٔ قیمت‌ها فعلاً استعلامی‌اند.
۶. WPML محلی به علت خطای لایسنس فروشنده غیرفعال است. ترجمه‌ها تا نصب WPML سالم و اتصال جفت‌ها منتشر نمی‌شوند. جفت‌های واردشده در گزینهٔ `barad_import_translation_pairs` نگه‌داری می‌شوند؛ ابزار هنگام فعال بودن WPML از API رسمی آن استفاده می‌کند.
۷. خروجی تازه برای جلوگیری از ایندکس پیش از آماده‌سازی، `blog_public=0` دارد. ایندکس، canonical، hreflang و sitemap را فقط پس از بازبینی دامنهٔ واقعی تنظیم کنید.

## پیش‌نمایش گیت‌هاب

`barad-preview` تصویر قابل مرورِ خروجی فعلی وردپرس است. صفحات، کالاها، دسته‌ها، جست‌وجوی مرورگری و پیوند برگه‌های فنی قابل مشاهده‌اند. این خروجی پنل مدیریت، ذخیرهٔ قیمت یا پردازش فرم‌ها ندارد؛ این قابلیت‌ها در نصب WordPress/PHP اجرا می‌شوند. اسکیما و canonical سایت واقعی در نسخهٔ نمایشی منتشر نمی‌شوند و پیش‌نمایش noindex است.
